# 個人研究室の試作品

`index.html` は見せるための研究室です。手帳を開くと自己紹介とリンクを読めます。入力・保存機能はなく、ブラウザ内の下書きも読み込みません。

`owner.html` は下書き用です。机の上の手帳を開くと、下から編集画面がスライドします。

できること：

- 研究員名と自己紹介の変更
- リンクの追加・削除と、モニター・ノート・標本瓶の選択
- 部屋でのプレビュー
- 机に置いた物のドラッグ配置（矢印キーでも移動可、Shiftで微調整）
- 配置をこの端末の下書きへ自動保存。リンクの名前・種類を変えても位置を引き継ぐ
- ↓で机の下を見て、引き出しを押して開く。↑で机の上に戻る
- 引き出しには瓶・ノート・モニターを物として並べる。中の物を押すとリンクが開く
- 机の物は勝手に収納しない。手帳の「机上の物」一覧から「保管庫へ送る」で収納する
- 保管庫の一覧では「机に戻す」で以前の机上の位置へ戻せる。移動はこの端末の下書きへすぐ保存する
- 引き出しは各6個まで。収納先が満杯なら次の空いた引き出しへ置き、収納台の左右移動でアクセスできる
- 手帳の「置き場所」で机・引き出しを選び直せる。引き出し内でも自由にドラッグできる
- 手帳の「机上の物・保管庫」→「引き出しの名前を編集」で名称を変更
- 物の名前は長さに合わせて伸びるマスキングテープに表示。長すぎる名前は画面から出ないよう折り返す
- 「触れたときに出る説明」を入力すると、マウスを重ねるかキーボードで選んだときに説明札が出る。タッチでは1回目で説明、2回目でリンクを開く
- 編集用では物のテープを押すと、その物の名前の編集欄が開く（F2でも可）
- 壁のスイッチで天井灯の点灯・消灯。「明るさ」を開いて5〜100%に調整。消灯しても緑の薬液は光る
- 照明の好みはこの端末に保存し、点け直したときに直前の明るさへ戻す。公開プロフィールや物の保存データは変更しない
- この端末のブラウザへの下書き保存
- 下書きの書き出し・読み込み

現在の「保存」は下書き保存です。公開中のデータや、他の端末の表示は変更しません。ブラウザの保存データを消すと下書きも消えるため、持ち出し機能で保管できます。

青緑の実験室に、上昇・変形する煙とゆっくり流れる霧を重ねています。動きは停止でき、端末の「動きを減らす」設定でも止まります。

`owner.html` での通常の保存は端末内の下書きだけに反映します。「公開に反映する」からGitHubの確認画面を開き、所有者本人のアカウントで承認した変更だけを公開します。サイト内にGitHubの認証情報を保存する必要はありません。
