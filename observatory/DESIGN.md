# 個人研究室 — 決まったこと

- 自己紹介と外部リンクのアクセスポイントとなる個人サイト。
- 添付参考画像の暗い実験室を基準にする。青白い照明、緑の薬液、金属、ガラス、配管、ゆっくりした霧。
- 落ち着き 7.7 / 不穏さ 2.3。居心地を優先し、驚かせる演出は加えない。
- リンクが増えると、研究室の中の物が増える。物はリンクの安定した ID に結びつける。
- 表示する研究員名は固定しない。本人があとから変更できること。
- 公開する名前はまだ決まっていない。GitHub のユーザー名を自動採用しない。
- 名前、自己紹介、リンクのデータは profile.js にまとめる。
- 机の上は最初は手帳だけ。手帳は下からスライドする見開き画面になる。
- 机の素材は金属。ステンレスを基準とした細い研磨目と、室内の青緑が映る鈍い反射に変更。
- リンクに対応する物の種類は本人が選ぶ（自動で決めない）。
- 机上の物は本人がドラッグして配置する方式に決定。owner.html でポインター・タッチ・矢印キーに対応。位置はリンクIDごとに机の割合座標として下書きへ保存し、書き出しにも含める。手帳は固定して開ける場所を確保する。
- 公開側は保存された位置を表示するだけで、ドラッグや保存のスクリプトを読み込まない。
- 可動域が狭いという本人の指摘を受け、机を画面下半分まで拡張。配置領域の上端を画面73%から49%へ変更（小画面46%）。
- 1画面6個を目安にし、追加分は番号付き保管棚へ割り当てる。棚の表示を切り替えられ、リンクは埋もれない。手帳で机・棚を選び直せる。棚では上下の段へスナップする。
- 上記の保管棚案は、本人のスケッチに合わせ「机の下の引き出し」に変更。画面下の↓で視点が下がり、↑で机に戻る。引き出しを押すとトレーが開き、中に瓶・ノート・モニターが物として並ぶ。
- 引き出し内も自由配置に変更。1個6リンクまで、収納台は引き出し6個ずつ。左右の矢印で別の収納台・引き出しへ移動できる。既存の surface=shelf / page データは番号を変えず引き出しとして表示し、互換性を保つ。
- 編集用では引き出しから手帳を開き直せる。公開側は物のリンクを開く閲覧専用。
- 本人の最新指定：机上の物は常時表示し、自動で保管庫へ移さない。机の6個制限は撤廃。手帳に「机上の物」「保管庫」の一覧を追加し、「保管庫へ送る」「机に戻す」で本人が整理する。
- 一覧からの移動はこの端末の下書きに即保存。机へ戻すときは元の机上位置を復元。移動後もカメラは勝手に切り替えない。「机で見てみる」は常に机上へ戻る。
- 引き出しの名前は手帳で変更可能にする。番号と内容は維持し、名札・トレーの見出し・保管庫一覧に反映する。
- 机の物には編集可能な名前をマスキングテープとして貼る。文字幅に合わせて横に伸び、画面幅を超える場合のみ折り返す。編集用ではテープを押して名前の編集欄を開く。
- 物ごとの短い説明を手帳で編集する。ホバー・キーボードフォーカスで説明札を表示。タッチは最初に説明を見せ、次のタップでリンクを開く。
- 壁に物理スイッチ風の照明操作を追加。天井灯の点灯・消灯と5〜100%の調光。オフでも薬液の緑を別レイヤーで残す。机・金属・物の陰影も連動し、手帳や操作部分は読める明るさを保つ。
- 調光値とオン/オフは照明専用キーで端末に保存。直前の調光値を点灯時に復元し、公開プロフィールには影響させない。
- 公開用 index.html の手帳は自己紹介・リンクの閲覧専用。フォーム・編集スクリプトを読み込まず、ブラウザの下書きも読み込まない。
- 編集方法は研究室の手帳を模した入力画面に決定。owner.html は下書き用の別画面。
- 現在、編集机で研究員名・自己紹介・リンク・物の種類を編集できる。リンクはモニター・ノート・標本瓶として表示される。追加・削除・プレビュー・ブラウザ内下書き保存・JSON書き出し/読み込みを実装。
- 保存は同じ端末・同じブラウザ内の下書きのみ。公開プロフィールは変更しない。公開前に本人認証と公開反映の経路を接続する必要がある。GitHubのパスワードやトークンを静的ファイル・ブラウザストレージへ保存する方式は採らない。
- 風景は参考画像を背景に使う青緑の実験室に変更済み。「蒼の観測所」の名称・都市・星空は初期案で終了。
- 画像自体は静止画。上にSVGの煙と霧を重ね、ゆっくり変形・上昇させる。停止ボタン・動きの軽減設定・タブ非表示に対応。
- owner.html の別URLや noindex は認証ではない。そこを開いても端末内の下書きしか変わらず、公開データを変更するAPIはない。公開反映の導線は未接続で、GitHubの本人認証を必須にする。
- 保存先は morusu16/morusu16.github.io。GitHub Pages 用の静的サイトとして制作する。
